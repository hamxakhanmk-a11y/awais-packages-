# Awais Packages

Independent copy of the Supreme Art website, ready for local editing.
Repository: https://github.com/hamxakhanmk-a11y/awais-packages-

## Start locally

Node.js is required (setup verified with Node 24). There are no package dependencies.

    npm run dev

Open http://localhost:3000. To update the preview after editing, run
`npm run build` in another terminal and refresh the browser.
The preview server serves static pages; it does not run the CMS login API.

## Where to make changes

- `content/`: page wording, shared navigation, contact details and image choices.
- `templates/`: page layouts; `templates/partials/` contains shared sections.
- `static/`: styles, browser scripts, images and CMS configuration.
- `api/`: CMS GitHub login functions for Vercel.
- `build.js`: merges content and templates into `dist/`.
- `serve.js`: local preview server.

Do not edit `dist/`: it is regenerated by every build.
The original branding and content are retained as the starting point for redesign.

## Check changes

    npm run build

The build validates JSON and fails on unresolved template values.
Review the affected pages in the local preview before committing.

## Publishing and the editor

Deployment is not configured or verified by local setup.
Create a separate Vercel project connected to this repository when ready.
The existing `vercel.json` builds with `node build.js` and serves `dist/`.

The CMS repository now targets this copy. Its URLs are local placeholders.
Before using hosted CMS login:

1. Set `backend.base_url` and `site_url` in `static/admin/config.yml` to the new deployment URL.
2. Create a GitHub OAuth app with callback `https://YOUR-DOMAIN/api/callback`.
3. Configure `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` and `ALLOWED_DOMAINS` on Vercel. Use the new hostname for `ALLOWED_DOMAINS`.
4. Review remaining Supreme Art branding, contact details, metadata and analytics before publishing.

`.env.example` documents deployment variables. Local preview needs none and
does not load environment files. Never commit credentials.
The optional deploy-hook workflow skips deployment when its secrets are absent.

## Template syntax

- `{{ a.b }}`: escaped value.
- `{{& a.b }}`: escaped value with line breaks.
- `{{{ a.b }}}`: trusted raw HTML.
- `{{> name }}`: shared partial.
- `{{#if x}}…{{else}}…{{/if}}`: conditional.
- `{{#each list}}…{{/each}}`: repeat.
- `{{#with obj}}…{{/with}}`: object scope.

Each page uses its matching content file as `page`, plus shared content as `site`.
